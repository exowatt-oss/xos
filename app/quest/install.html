Set up Xos Quest

Install on each headset once; videos, scenes, pairing and controller updates come from Xos.

Download Xos Quest · v1.0.0 APK Open Demo Studio

  1. Connect a developer-mode Quest to your Mac using USB. Wake the headset, put it on, and allow USB debugging for your Mac. Keep each headset on Wi-Fi with access to your Xos server.
  2. Install from the Mac. Use Meta Quest Developer Hub’s APK installation feature, or install Android Platform Tools and run:

    adb install -r ~/Downloads/xos-quest.apk

    With multiple USB headsets, use adb devices -l to find the serial, then adb -s SERIAL install -r ~/Downloads/xos-quest.apk. Repeat for each headset. An iPad controls demos after installation; USB installation uses a computer.
  3. Open Xos Quest. On the headset, find it under Library → Unknown Sources. It launches the immersive viewer. If VR does not start automatically, choose Enter VR. A six-digit pairing code appears in the app.
  4. Pair from your iPad or Mac. Open Xos → Demo Studio → Add headset. Select the headset's site, choose a free slot, and enter the code. Confirm the live connection, VR state and preview checks.
  5. Present. Select headsets, choose a walkthrough, and start. Use Recenter or Fix / settings on a headset card, or Headset tools & settings for the selected group. Cards show queued, applied, failed or expired recovery actions.

Fix a connection

Keep the headset awake and Xos in the foreground. If Xos is closed or fully frozen, reopen it locally. Check Wi-Fi and the Xos address in Quest Browser. Pairing survives app updates when you install with -r; clearing app/site data or uninstalling requires pairing again.

Remote tools adjust the Xos scene and app settings. Meta’s physical boundary, system volume, Wi-Fi, power and operating-system restart remain in the headset’s system settings. App-view previews show Xos content only.

The APK uses Meta’s immersive PWA packaging and requires a network connection. This developer-mode build is not a Horizon Store listing. Physical headset validation remains required before customer demos.
